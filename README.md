# Hi, I'm Furkan Sağlam 👋

I explore machine learning, computer vision, and natural language processing through academic projects. My work also spans Java and Android applications, data structures, embedded programming, and digital logic design.

I enjoy understanding how systems work—from implementing neural network components to building the datapath of an 8-bit CPU.

## What I work with

- **Machine learning & computer vision:** Python, NumPy, PyTorch, OpenCV, Tesseract, scikit-learn, Gradio
- **Natural language processing:** NLTK, character n-grams, Hidden Markov Models, TF-IDF, Word2Vec
- **Application development:** Java, Swing, Android, PHP, MySQL, JDBC
- **Computer science & hardware:** C, C++, Haskell, AVR Assembly, Verilog, Logisim, Raspberry Pi
- **Analysis & simulation:** Jupyter, MATLAB, OMNeT++, Cisco Packet Tracer

## Selected projects

### Machine learning & computer vision

- **[MNIST Neural Network from Scratch](https://github.com/furkansaglam/mnist-neural-network-from-scratch)** — Explore neural network layers, forward and backward propagation, and SGD with momentum for handwritten-digit classification using HOG features and a PyTorch reference.
- **[Personal Face Recognition](https://github.com/furkansaglam/personal-face-recognition)** — An educational binary face classifier using ResNet18 transfer learning, model evaluation, and a Gradio prediction interface.
- **[Smart Attendance OCR](https://github.com/furkansaglam/smart-attendance-ocr)** — A Raspberry Pi prototype for reading student cards with OpenCV and Tesseract, with GPIO feedback and CSV logging.

### Natural language processing

- **[Character N-gram Language Identification](https://github.com/furkansaglam/character-ngram-language-identification)** — English–Turkish language identification using character n-grams, Laplace smoothing, and cross-validation.
- **[HMM POS Tagging & Text Generation](https://github.com/furkansaglam/hmm-pos-tagging-text-generation)** — Explore supervised, unsupervised, and semi-supervised Hidden Markov Models with NLTK.
- **[NLP Representation Robustness](https://github.com/furkansaglam/nlp-representation-robustness)** — Evaluate TF-IDF and Word2Vec document representations under noise using similarity retrieval and ranking metrics.

### Applications & computer architecture

- **[Campus Bookstore Management System](https://github.com/furkansaglam/campus-bookstore-management-system)** — A Java Swing application for managing students, employees, and textbook reservations, with MySQL/JDBC and file persistence.
- **[Hocam Program](https://github.com/furkansaglam/hocam-program)** — Collaborative Android Java and PHP/MySQL coursework for managing students, lessons, attendance, and payment records. Published as a source snapshot.
- **[8-bit CPU in Logisim](https://github.com/furkansaglam/8-bit-cpu-logisim)** — A single-cycle processor integrating an ALU, register file, instruction and data memory, and branch/jump control.
